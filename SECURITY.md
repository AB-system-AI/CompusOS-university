# Security Policy

## Supported Versions

| Version | Supported           |
| ------- | ------------------- |
| 1.0.x   | Yes (when released) |
| < 1.0   | No (pre-release)    |

## Reporting a Vulnerability

**Do not** open public GitHub issues for security vulnerabilities.

Email: security@campusos.com

Include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Affected components/services

## Response SLA (CEC §10)

| Severity                        | Response Time |
| ------------------------------- | ------------- |
| SEV-1 (Active breach)           | 15 minutes    |
| SEV-2 (Exploited vulnerability) | 1 hour        |
| SEV-3 (Suspicious activity)     | 4 hours       |
| SEV-4 (Policy violation)        | 24 hours      |

## Security Standards

CampusOS follows:

- OWASP Top 10 mitigations (CEC §10.2)
- Zero Trust architecture (EAP §8)
- Secure SDLC with SAST/DAST/secret scanning in CI

## Coordinated Disclosure

We follow coordinated disclosure. Researchers who report valid vulnerabilities in good faith will be acknowledged (with permission) after remediation.
